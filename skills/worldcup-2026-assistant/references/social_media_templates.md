# 赛后社交文案模板

根据比赛结果，一键生成三种风格的社交内容。

## 朋友圈短评模板（50字以内）

### 大胜场景
- 「{比分}！{赢球队}今晚太炸了💥 {关键球员}直接封神！#世界杯2026」
- 「看{赢球队}踢球就是享受，{比分}完胜{输球队}⚽ 这届世界杯有看头了」

### 惜胜/绝杀场景
- 「心脏不好的别看世界杯😅 {赢球队}{比分}绝杀{输球队}，最后{分钟}分钟我差点原地去世」
- 「这就是足球啊！{赢球队}{比分}{输球队}，{关键球员}第{分钟}分钟绝杀🔥」

### 平局场景
- 「{主队}{比分}{客队}，踢了个寂寞😐 出线形势又乱了」
- 「平局大师们⚽ {主队}vs{客队}{比分}，谁也没占到便宜」

### 冷门场景
- 「世界杯果然什么都可能发生😱 {弱队}{比分}{强队}！谁猜到了？」
- 「爆冷！{强队}被{弱队}{比分}击败💀 赌球的朋友们还好吗？」

### 本国球队场景
- 「{国家队}今天{比分}{结果}！🇨🇳 {一句感受} #中国队加油」
- 「看{国家队}比赛需要勇气💪 {比分}{结果}，{一句鼓励}」

## 公众号深度分析模板（500-800字）

### 结构
```
# {主队} {比分} {客队}：{一句话总结}

## 比赛概况
{比分、进球时间、关键事件，2-3句话}

## 战术分析
{阵型、打法、关键战术变化，3-4句话}

## 关键球员
- {球员1}：{表现评价}
- {球员2}：{表现评价}
- {全场最佳}：{为什么}

## 数据说话
- 控球率：{主队}% vs {客队}%
- 射门：{主队} vs {客队}
- 射正：{主队} vs {客队}
- xG（预期进球）：{主队} vs {客队}

## 出线形势
{这场比赛对两队出线的影响}

## 下一场展望
{两队接下来的对手和前景}

#世界杯2026 #{主队} #{客队}
```

```
# 阿根廷 2-1 法国：梅西的最后一舞还在继续

## 比赛概况

法国在下半场变阵4-2-4加强进攻，但后防空档被阿根廷利用...

## 关键球员

- 姆巴佩：速度依旧惊人，但被阿根廷防线限制
- 全场最佳：梅西
```

## 小红书图文模板

### 标题公式
- 数字+情绪：「世界杯惊天冷门！{弱队}{比分}击败{强队}，评论区炸了」
- 疑问式：「{球员}这球算不算越位？裁判看了3分钟VAR终于给了答案」
- 对比式：「{球员A}vs{球员B}，谁才是本届世界杯第一人？数据说话📊」
- 感叹式：「太燃了！{球队}最后{分钟}分钟连进{数量}球逆转比赛🔥」

### 正文结构
```
{emoji} {一句话开头，制造悬念}

⚽ 比赛回顾：
{简短描述比赛进程，3-5句话}

📊 关键数据：
• 控球率：{数据}
• 射门次数：{数据}
• 最佳球员：{球员}（{评分}分）

💡 我的分析：
{2-3句个人观点，可以有争议性}

👇 互动话题：
{提问引导评论，如：你觉得谁是全场最佳？}

#世界杯2026 #{球队1} #{球队2} #足球
```

### 评论引导话术
- 「你觉得这场比赛谁表现最好？评论区告诉我👇」
- 「{球队}能走多远？预测一下冠军🏆」
- 「看完这场比赛你什么感受？我先说：______」
- 「{球员}这表现值几分？打在评论区💬」

## 内容生成规则

1. **数据必须真实**：所有比分、进球时间、数据必须来自 football-data 查询结果
2. **情绪要到位**：朋友圈要短平快有梗，公众号要专业有深度，小红书要有互动感
3. **时效性**：比赛结束后2小时内发布效果最好
4. **避免敏感内容**：不涉及政治、地域歧视、人身攻击
5. **适度使用emoji**：朋友圈和小红书可以多用，公众号适度使用
